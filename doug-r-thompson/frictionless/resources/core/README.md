# Core starter pack — Available now

Use the six files in this folder in this order:

1. `quick-start.pdf` — follow a 30-minute process.
2. `friction-evidence-card.pdf` — record a concrete observed issue.
3. `friction-ledger.xlsx` — quantify repeated, avoidable effort.
4. `stakeholder-alignment.xlsx` — identify decision makers, costs and a pilot.
5. `improvement-scorecard.xlsx` — record before/after outcomes.
6. `worked-example.pdf` — see fictional inputs and interpretation.

In the Excel files, the sample entries are fictional and are labeled as such. Copy/replace them with your own data; do not place personal or confidential information in the public repository.

For screen-reader-friendly guidance, refer to the accompanying [HTML resource hub](../../index.html) and the `README.md`; the PDFs are optimized primarily for clear printing.
